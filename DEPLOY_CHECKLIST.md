# Deployment Checklist

- [ ] Run `npm install`.
- [ ] Run `npm run build` and resolve all errors.
- [ ] Inspect desktop + mobile locally.
- [ ] Initialize Git.
- [ ] Confirm secrets are ignored.
- [ ] Create GitHub repository and push.
- [ ] Import repository into Vercel.
- [ ] Confirm framework detection is Next.js.
- [ ] Deploy production.
- [ ] Test the public URL in a private browser.
- [ ] Test homepage mission filters.
- [ ] Test at least three mission detail pages.
- [ ] Test official source links.
- [ ] Test on a phone.
- [ ] Set `NEXT_PUBLIC_SITE_URL` to the final URL.
- [ ] Optionally add `CRON_SECRET` before real scheduled ingestion.
- [ ] Optionally attach a custom domain.
- [ ] Keep GitHub → Vercel automatic deployments enabled.
